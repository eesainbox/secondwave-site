# SecondWave Inbox — Brand Guidelines

## Colors
- Primary Background: #0C1935 (deep navy, near-black)
- Primary Text: #FFFFFF (white)
- Muted Text: #A0AEC0
- CTA Accent: pull from the icy electric blue in the wave curl on SecondWave_Logo_1.png
- Flow Track: #00B4A6 (teal)
- Campaigns Track: match CTA electric blue
- Full Stack Track: #F5A623 (amber/gold)
- Always dark background. Never light mode. Never white sections.

## Typography
- Font family: 'Helvetica Neue', Helvetica, Arial, sans-serif
- This is a system font — no import or CDN needed
- Heading weight: 700-800
- Heading tracking: -0.03em on display sizes
- Body weight: 300-400
- Body size: 16px minimum
- Body line-height: 1.7

## Logo
- Nav: SecondWave_Logo_1.png (wave mark + wordmark, navy background)
- Footer: SecondWave_Logo_2.png (wave mark + wordmark, black background)
- Mobile nav: wave mark only (crop from logo file)
- Never place logo on a light background
- Minimum clear space: equal to wave mark height on all sides

## Voice
- Direct. Performance-focused. No fluff.
- Reads like the agency already did the work.
- No hype. No superlatives. No generic agency language.
- No em dashes.
- No word "retainer" — always say "ongoing management."
- No Upwork mentions on public-facing pages.
